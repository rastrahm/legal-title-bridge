// 01 — CONTEXTO

Por qué este proyecto

Un título legal tokenizado no puede vivir en dos verdades. Este módulo fija Ethereum como fuente de verdad (TitleRegistry estilo ERC-3643), espeja en Solana Token-2022 con transfer hook, cruza mensajes vía BridgeEndpoint 2-of-3 y cierra ventas con escrow DvP (plazos D4–D6). Laboratorio en Sepolia + Solana Devnet, no mainnet ni asesoramiento legal.

// 02 — CINCO PILARES

Qué entrega el módulo

// PILAR_01

TitleRegistry

Ethereum manda: unidades por activo, compliance modular y asientos encadenados. Solana espeja con Token-2022 + transfer hook.

  • ERC-3643-style + LedgerChain
  • Token-2022 permanent delegate
  • UnauthorizedTransferPath
// PILAR_02

BridgeEndpoint

Quórum 2-of-3 de relayers, dominios/épocas, anti-replay por messageId y límites de flujo con pausa de guardián.

  • RelayerQuorum · WrongDomain
  • MessageAlreadyProcessed
  • FlowLimitExceeded · Timelock
// PILAR_03

DvP escrow

Escrow atómico en Solana: depósito, decisión Ethereum y settlement/refund bajo plazos D4–D6.

  • D4 soft · D5 hard · D6 reconcile
  • MintMismatch · PDA seeds
  • LateApprovalRejected
